# 项目阶段计划

项目定位：面向土耳其本地读者的**时尚与消费生活原创资讯站**，主要使用土耳其语。重点栏目为时尚、美妆、美食、健康、运动、购物、消费科技、旅游和生活方式。

原则：每阶段完成后先测试、汇报并等待项目所有者确认，再进入下一阶段。未经确认不启用生产采集、不产生付费调用、不绑定正式域名。

## 阶段 1：项目基础与定位

- [x] 建立独立 GitHub 仓库
- [x] 明确静态网站方向
- [x] 明确初期不使用数据库
- [x] 明确无注册、登录和会员功能
- [x] 固定自动扫描目标为每 30 分钟一次
- [x] 记录技术架构、来源政策和阶段路线图
- [x] 初步核查官方 RSS 目录与公开使用条款
- [x] 形成来源核查报告与无数据库内容模型草案
- [x] 建立默认禁用的候选来源配置
- [x] 将网站定位调整为土耳其时尚与消费生活原创资讯站
- [x] 更新土耳其语栏目与内容模型
- [ ] 项目所有者审阅并确认本次定位调整

验收：文档、栏目配置与项目定位一致；无未批准的付费依赖。

## 阶段 2：内容来源与编辑规则

- 以时尚、美妆、美食、健康、运动、购物、科技消费、旅游和生活方式为选题领域。
- 优先寻找明确允许自动访问和相应用途的官方资料、开放数据、研究资料与赛事信息。
- 不把公开可访问或存在 RSS 等同于转载、商业使用或图片授权。
- 不以逐家媒体 RSS 转载授权作为网站启动的前提；对限制自动访问或禁止相应用途的来源不自动采集。
- 定稿来源记录、事实核验、署名、图片使用和更正规则。
- 建立原创指南、趋势观察、解释文章和动态资讯的内容模板。
- RSS 手动测试工作流仅用于未来明确获准的单次技术测试，不作为生产采集或定时任务。

验收：首批来源有可追溯的使用依据；内容模板和事实核验规则可执行；未授权来源保持禁用。

## 阶段 3：静态网站最小版本

- 初始化 Astro + TypeScript 项目。
- 建设土耳其语首页、栏目页、文章详情页、关于 / 来源说明页。
- 首页突出 Moda、Güzellik、Yeme-İçme、Sağlık、Spor 等核心栏目。
- 实现土耳其语页面元数据、SEO 基础和 Sitemap。
- 用原创样例 Markdown 内容构建。
- 检查移动端布局、页面速度、无障碍与链接。

验收：本地构建成功，样例页面和栏目正确；未接入生产采集。

## 阶段 4：内容发现与编辑流水线（先手动触发）

- 编写合规来源信息获取与规范化逻辑。
- 实现去重、时间检查、来源记录和错误日志。
- 实现土耳其语原创标题、摘要、文章起草、分类、标签及质量检查。
- 健康内容增加证据等级、免责声明和高风险人工审核门槛。
- 运动赛果、价格、促销和产品参数必须核实来源与时间。
- 接入 AI 编辑服务前，先确认供应商、费用和每月上限。
- 先以手动触发方式测试，不启用 30 分钟生产计划任务。

验收：测试数据通过；重复、过期、无来源和事实冲突案例按规则处理；成本可测算。

## 阶段 5：自动调度与安全部署

- 经批准后将信息扫描调度目标设置为每 30 分钟一次。
- 设置并发保护、重试上限、失败记录和运行指标。
- 配置 GitHub Secrets，不在仓库保存密钥。
- 验证 Astro 构建及 Cloudflare Pages Direct Upload。
- 验证部署失败回滚和额度监控。
- 先小范围观察，再由项目所有者批准正式启用。

验收：调度、构建、部署、日志和成本监控均经过测试。

## 阶段 6：上线前审核与发布

- 审查土耳其语内容质量与事实准确性。
- 完成土耳其当地法律、版权、广告披露、消费者与健康内容合规核查。
- 检查来源署名、图片授权、隐私、纠错和联系信息。
- 绑定域名（如需购买域名，先单独确认预算）。
- 进行安全、SEO、移动端和可用性检查。
- 经项目所有者最终批准后公开发布。

## 阶段 7：运行观察与优化

- 观察来源可用率、内容质量、重复率、更新时间和错误率。
- 观察页面访问、搜索索引和用户反馈。
- 根据实际表现调整栏目与选题，不改变每 30 分钟的固定扫描要求，除非项目所有者明确批准。
- 只有在确有必要并完成成本评估后，才考虑数据库、对象存储或付费服务。
