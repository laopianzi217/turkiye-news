# 内容来源与版权原则

## 1. 网站定位

本网站定位为面向土耳其本地读者的**时尚与消费生活原创资讯站**，以土耳其语发布。重点领域包括：

- Moda — 时尚、穿搭、服饰趋势
- Güzellik — 美妆、护肤、香水
- Yeme-İçme — 美食、餐饮、食谱、饮食趋势
- Sağlık — 健康、营养、睡眠、健康生活
- Spor — 体育赛事、运动、健身
- Alışveriş — 购物、品牌、新品、消费指南
- Teknoloji — 消费电子与智能设备
- Seyahat — 旅游、度假、本地目的地
- Yaşam — 家居、家庭与生活方式
- Kültür-Sanat — 文化、娱乐与活动

网站不以转载传统新闻全文或镜像 RSS 内容为目标。RSS 只是可能的信息发现渠道，不是内容策略本身。

## 2. 来源优先级

优先考虑：
1. 明确允许相应用途的官方开放数据集。
2. 政府、公共机构、大学、研究机构发布的公开资料与公告，并逐项核实使用条件。
3. 体育协会、赛事组织方、俱乐部、品牌和活动主办方的官方信息；核对自动访问、商用、引用和再利用条件。
4. 明确允许相应用途的官方 RSS / Atom / API。
5. 具备明确授权或适用开放许可的图片、数据和其他素材。
6. 可独立核实的公开信息，用于原创报道和背景解释；不得把可浏览等同于可复制。

不必为了启动网站而逐家申请所有媒体的 RSS 转载授权。应优先设计原创选题和合规信息发现流程；对明确禁止自动访问或限制相关用途的来源，不进行自动采集。

## 3. 来源使用检查

每个自动化来源至少记录：
- 机构 / 发布者名称、官方入口、来源类型
- 许可或使用条款链接、核查日期
- 是否允许自动访问及速率限制
- 允许保存和处理的字段
- 是否允许商业使用、衍生内容、再发布
- 署名和原文链接要求
- 图片、视频、商标等素材是否有独立授权
- 最近测试时间、解析结果与错误率

开放数据许可只覆盖明确标注的数据集，不自动覆盖同一机构的新闻稿、图片、标志或第三方材料。无法确认权利范围时，不自动抓取或发布该来源内容。

## 4. 原创编辑规则

- 使用土耳其语撰写原创标题、导语、解释、指南和趋势分析。
- AI 只能辅助整理、翻译、分类和起草；事实必须可追溯，不得编造人物、报价、日期、产品规格、赛事结果或研究结论。
- 不复制整篇原文，不绕过付费墙或访问控制。
- 不抓取或重新托管来源图片，除非明确获得许可或适用授权；优先使用自制视觉、已授权素材或明确许可的图片。
- 对事实来源进行适当署名并链接原始资料。
- 对不确定、尚未证实或来源相互冲突的信息明确说明，必要时不发布。
- 更正或撤回内容时，保留修订记录并及时更新页面。

## 5. 垂直领域质量要求

- **健康**：优先卫生部门、医院、大学、同行评审研究和专业公共卫生机构；注明研究局限，不作个人诊断，不提供无依据的治疗建议。
- **运动**：赛事结果、积分、赛程和球员数据必须来自可核实且允许相应用途的来源；区分官方确认与传闻。
- **美食 / 时尚 / 购物**：价格、促销、产品参数和品牌声明需标注时间与来源；不得把广告或品牌宣传包装成独立验证结论。
- **旅游 / 本地生活**：开放时间、票价、交通和地点信息可能变化，发布时记录核验日期。

## 6. 核实与审核级别

- 普通生活方式内容：至少有可追溯依据，完成编辑和链接检查。
- 重要消费、健康或体育信息：使用第二个独立可信来源核对关键事实。
- 重大健康风险、公共安全、伤病、指控或敏感事件：必须人工审核；不允许仅凭 AI 或单一来源自动发布。
- 发现来源冲突时，明确标注不确定性或暂缓发布。

## 7. 既有来源核查记录

历史 RSS / 官方来源核查仍保存在 [SOURCE-VERIFICATION.md](SOURCE-VERIFICATION.md)。其中标记待确认或需许可的来源，不因网站定位调整而自动获得授权，也不会自动启用。

## 8. 法律核查

面向土耳其公众运营网站，可能涉及版权、消费者保护、广告披露、健康信息、个人数据及出版责任等法规。正式上线前应由熟悉土耳其法律的专业人士核查适用义务。本文件不是法律意见。
