# 新闻来源接入与版权原则

## 1. 接入优先级

按以下顺序评估新闻来源：

1. 明确允许相应用途的官方开放数据集。
2. 新闻机构官方 RSS / Atom Feed，且取得适用的再发布许可。
3. 新闻机构提供且允许相应用途的官方 API。
4. 政府部门、公共机构的官方公告与数据，且逐项核实使用条件。
5. 与权利人明确授权的其他数据源。

不得把“网页可访问”或“RSS 可读取”理解为获得了转载、商业使用或图片使用授权。开放数据许可只覆盖其明确标注的数据集，不自动覆盖同一机构的新闻稿、照片、标志或第三方材料。

## 2. 候选来源

当前没有任何来源获准进入生产自动采集。所有配置默认 disabled。当前核查结果见 [SOURCE-VERIFICATION.md](SOURCE-VERIFICATION.md)；内容字段与文件存储结构见 [CONTENT-MODEL.md](CONTENT-MODEL.md)。

候选包括 TRT Haber、Habertürk、土耳其外交部、文化和旅游部、卫生部开放数据平台等。TRT Haber、Habertürk、文化和旅游部均需先取得或确认适用许可；外交部 RSS 仍需确认再发布条件；卫生部开放数据仅可逐数据集按其明确许可评估，不能当作新闻 Feed。Anadolu Ajansı 需要订阅合同，不纳入免费来源假设。

## 3. 来源验证清单

每个来源至少记录：

- 机构名称、官方网站及 Feed/API/数据集官方链接
- 来源类型（媒体 / 政府 / 公共机构 / 开放数据）
- 是否官方发布
- 是否允许自动访问及相关速率限制
- 是否允许保存标题、摘要、正文、缩略图或其他字段
- 是否允许商业使用、再发布或衍生摘要
- 具体许可名称、版本、适用范围及署名要求
- 版权 / 使用条款链接与核查日期
- 最近一次成功抓取时间、解析结果和错误率
- 是否作为重大新闻的独立交叉验证来源

无法确认权利范围时，只保留必要的来源标识与链接，并暂停自动发布；必要时联系权利人取得书面许可。

## 4. 编辑与版权规则

- 默认只生成原创土耳其语标题、摘要、分类和标签。
- 不复制整篇原文，不绕过付费墙或访问控制。
- 不抓取或重新托管来源图片，除非明确获得许可或适用的授权。
- 对来源事实进行忠实转述，不能添加来源未支持的事实。
- 在新闻详情页清晰标注来源机构并链接原文。
- 摘要长度、引用范围和署名规则应根据每个来源的条款确定，而不是采用统一的“可复制”假设。
- 若来源内容被更正或撤回，应保留修订记录并及时更新或撤下相关页面。

## 5. 多来源核实与审核级别

- 普通新闻：检查来源可信度、发布时间、原文链接和摘要一致性。
- 重要新闻：尽可能使用至少两个相互独立的可信来源核对关键事实。
- 重大 / 敏感新闻：进入人工审核，不允许单一来源触发自动公开发布。
- 来源之间存在冲突时，明确标注不确定性或暂缓发布，不得自行拼接成确定结论。

## 6. 法律核查

面向土耳其公众运营新闻网站，可能涉及新闻出版、媒体责任、个人数据保护、版权及其他当地法规。上线前应由熟悉土耳其法律的专业人士核查适用义务，包括出版者信息、编辑责任、内容留存、纠错和个人数据处理要求。本文件不是法律意见。
